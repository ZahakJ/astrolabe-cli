Your Markdown notes, beautifully, in the terminal.

Astrolabe CLI is a reader that typesets your notes, a small Vim-style editor and a set of shell verbs for capture and search, in one static binary. It opens any folder of .md files, or an Obsidian vault exactly as it is, and adds nothing to it: no database, no index on disk.

Install Read the manual

Capture and search from the shell

astrolabe add appends exactly one line to today's daily note and changes nothing else in the file; -t makes it a task. find, ls, tasks, backlinks and pick answer from the shell, with --json for scripts.

Run astrolabe -C ~/my-notes once and that folder is remembered; plain astrolabe then opens it from anywhere.

Read, edit, keep track

Move with j k, jump between headings with ]], fold with za, follow a link with Tab and Enter. Press i to edit the line under the cursor in the built-in editor, where Vim keys work; Esc twice saves and puts you back where you were.

Space t is the agenda of every open task in the vault, by due date. x ticks a task by rewriting one character in the file. Writes are atomic, and a file that changed on disk is never overwritten without asking.

Arabic, right to left, in any terminal

Most terminals print Arabic with its letters unjoined and its words backwards. Astrolabe CLI shapes and orders the text itself, with a separate mode for kitty, which reverses right-to-left runs once more on its own. astrolabe doctor says which mode it chose and why.

Search folds Arabic: harakat and tatweel are ignored, and أ إ آ match ا, so the plain spelling finds every form.

Install

On Linux or macOS, as yourself (no root):

curl -fsSL https://raw.githubusercontent.com/ZahakJ/astrolabe-cli/main/install.sh | sh

It puts one static binary of about 5.5 MB in ~/.local/bin, checked against the release checksums, with the short alias ast. Then try it on the sample vault, or point it at your notes:

astrolabe doctor
astrolabe -C ~/my-notes
